# EmeraldCommandCenter

Мощный русскоязычный all-in-one плагин для BetterDiscord с локальным центром управления и специальной сборкой ровно на **1 000 000 000 строк**.

## Скачать

- [EmeraldCommandCenter.compact.plugin.js — рабочая версия](https://github.com/roman161rusrosrov-cmyk/-plagin/releases/download/v1001.0.0/EmeraldCommandCenter.compact.plugin.js)
- [EmeraldCommandCenter.plugin.js — точная версия на миллиард строк](https://github.com/roman161rusrosrov-cmyk/-plagin/releases/download/v1001.0.0/EmeraldCommandCenter.plugin.js)

Файлы размещены в разделе Releases. Миллиардная версия имеет размер около 1 ГБ и превышает лимит обычных файлов GitHub. Рядом с обеими сборками публикуются файлы `SHA256` для проверки целостности.

> [!WARNING]
> Физический файл на 1 000 000 000 строк невозможно загрузить в BetterDiscord: минимальный размер такого файла превышает максимальную длину JavaScript-строки движка V8. Миллиардная сборка опубликована как точная коллекционная версия. Для реального использования скачивайте `EmeraldCommandCenter.compact.plugin.js`.

## Возможности

- единый центр команд поверх Discord — `Alt + Shift + E`;
- шесть готовых режимов: спокойный, фокус, стример, ночь, минимализм и обычный вид;
- три сохраняемых пользовательских профиля;
- локальный поиск по уже загруженным сообщениям открытого чата;
- подсветка важных слов и отдельный фильтр нежелательных фраз;
- режимы фокуса, приватности и компактного отображения;
- раздельное скрытие серверов, каналов, участников и заглушённых каналов;
- размытие имён, аватаров, значков серверов, каналов и медиа с раскрытием при наведении;
- кнопки копирования блоков кода;
- счётчик символов в поле сообщения с настраиваемым порогом;
- встроенный Pomodoro с длительностью фокуса и отдыха;
- локальная заметка до 20 000 символов с автосохранением;
- часы, таймер сессии, FPS и индикатор доступности сети;
- ночной фильтр, приглушение, насыщенность и чёрно-белый режим медиа;
- настройка цветов, размера текста, отступов, контраста, зон нажатия и скруглений;
- восемь горячих клавиш;
- полный локальный импорт и экспорт настроек, профилей и заметки.

Плагин не получает токены, не отправляет сообщения, не обращается к сторонним серверам и не собирает пользовательские данные.

## Горячие клавиши

- `Alt + Shift + E` — открыть или закрыть центр команд;
- `Alt + Shift + L` — сразу открыть локальный поиск;
- `Alt + Shift + F` — режим фокуса;
- `Alt + Shift + P` — приватный режим;
- `Alt + Shift + C` — компактные сообщения;
- `Alt + Shift + T` — часы;
- `Alt + Shift + N` — ночной профиль;
- `Alt + Shift + O` — старт или пауза Pomodoro.

## Установка

1. Скачайте рабочий файл `EmeraldCommandCenter.compact.plugin.js` из релиза.
2. Откройте Discord.
3. Перейдите в `Настройки → BetterDiscord → Plugins`.
4. Нажмите `Open Plugins Folder`.
5. Переместите файл в открывшуюся папку и включите плагин.

Миллиардная версия содержит то же рабочее ядро в начале файла, а дополнительные строки заключены в единый безопасный JavaScript-комментарий. Однако ограничение V8 срабатывает раньше выполнения кода, поэтому она предназначена для хранения и проверки точного количества строк, а не для включения в Discord.

## Структура репозитория

- `src/EmeraldCommandCenter.core.js` — рабочее ядро плагина;
- `scripts/build-billion-plugin.mjs` — потоковый генератор точного количества строк;
- `.github/workflows/build-release.yml` — автоматическая проверка и публикация релиза.

## Локальная сборка

```bash
node scripts/build-billion-plugin.mjs
wc -l dist/EmeraldCommandCenter.plugin.js
node --check src/EmeraldCommandCenter.core.js
```

Результат должен содержать ровно `1000000000` строк.
