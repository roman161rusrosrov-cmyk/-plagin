# PowerDiscord 3.1 — Chat Tools

Производительный русскоязычный all-in-one плагин для BetterDiscord. В версии 3.1 сохранены ровно **100 курируемых функций**, добавлен закреплённый блок безопасных инструментов чата, а весь интерфейс остался в мягких фиолетовых тонах.

Возможности:

- закреплённый блок: одноразовый чек текущего чата, сохранение выбранного медиа/аватара, инструменты кода, фильтры интерфейса и подсказка голосовых клавиш;
- чек чата считает только агрегированные метрики уже отрисованных сообщений: сообщения, слова, ссылки, блоки кода, медиа, упоминания, вложения, повторы и слишком длинные сообщения; текст никуда не записывается;
- блоки кода получают кнопку копирования и отдельную нумерацию строк без разрушения подсветки синтаксиса;
- сохранение изображения, видео или аватара после наведения курсора — без дополнительного `fetch` и без фоновой загрузки переписки;
- `Alt + Shift + M` нажимает видимую кнопку микрофона, `Alt + Shift + D` — видимую кнопку приглушения звука;
- фильтры для скрытия уже показанных Discord недоступных каналов и анимированных медиа;
- читаемый системный шрифт, размер текста, компактный список участников и скрытие кнопок подарка/GIF;
- 10 фиолетовых палитр: глубокая, лавандовая, аметистовая, индиго, сливовая, кибер, орхидея, мягкая, чёрно-фиолетовая и светло-сиреневая;
- компактный интерфейс, режим фокуса, приватное размытие, медиа-фильтры и адаптивная компоновка;
- настройка текста, скругления, яркости, насыщенности, ширины панелей и размеров значков;
- русская панель с поиском, категориями и избранным; есть переключатель RU/EN;
- текстовая лаборатория: регистры, строки, цитаты, спойлеры, JSON, URL, Base64 и транслитерация;
- копирование текста, ID, ссылки и цитаты только для сообщения, на которое пользователь сам навёл курсор;
- локальная подсветка или временное скрытие видимого сообщения;
- закладки хранят только ID и ссылку перехода, без текста сообщения;
- пользовательские заметки к позиции сообщения;
- поиск среди каналов, уже показанных Discord пользователю;
- копирование URL, увеличение и сброс видимого изображения или видео;
- резервная копия JSON, диагностика и полный сброс;
- плавающая кнопка, приватность при сворачивании, кнопки копирования кода, счётчик символов и Responsive Engine;
- полная очистка observer-ов, listeners, DOM-элементов, классов, медиа-стилей и CSS при выключении.

## Что ускорено

- MutationObserver обрабатывает только реально добавленные DOM-ветки и не следит за каждым изменённым символом;
- несколько DOM-изменений объединяются в один кадр через `requestAnimationFrame`;
- счётчик сообщения обновляется от события ввода, а не от полного пересканирования чата;
- Responsive Engine меняет только режим окна и статистику, не перестраивая список функций;
- меню сначала создаёт 32 карточки и подгружает остальные порциями;
- поиск запускается после короткого debounce;
- частые движения ползунков объединяются в одну запись настроек;
- вкладка Discord в фоне не запускает DOM-обработку до возвращения пользователя;
- режим `⚡ Лёгкий` отключает фильтры и observer-зависимые украшения одним нажатием.

Дополнительные плюшки: быстрые профили `Лёгкий / Комфорт / Приватность`, случайная фиолетовая тема, просмотр локальных закладок и заметок, восстановление временно скрытых сообщений и расширенная диагностика нагрузки.

## Безопасность

PowerDiscord не читает токены, cookies, пароли или session keys, не делает сетевые запросы, не пишет сообщения от имени пользователя и не обходит Nitro либо права Discord.

Плагин не раскрывает содержимое закрытых каналов и не ведёт журнал удалённых или изменённых сообщений. Он не скрывает статус набора текста, не блокирует внутренние подтверждения прочтения, не патчит шумоподавление и не переключает аудиоустройства через закрытые модули. Автоперевод не включён, потому что без локальной модели он потребовал бы передавать текст переписки стороннему сервису.

Такой предел выбран намеренно: правила BetterDiscord запрещают журналирование сообщений, раскрытие удалённых сообщений/скрытых каналов и функции, повышающие риск для аккаунта.

## Установка

1. Установите [BetterDiscord](https://betterdiscord.app/).
2. Скачайте `PowerDiscord.plugin.js` из релиза.
3. Откройте Discord → `Настройки пользователя` → `BetterDiscord` → `Plugins`.
4. Нажмите `Open Plugins Folder`, перенесите туда файл и включите PowerDiscord.
5. Откройте центр кнопкой `PD` или сочетанием `Ctrl + Shift + P`.

`Alt + Shift + P` включает мгновенное приватное размытие.

`Alt + Shift + M` переключает штатную кнопку микрофона, `Alt + Shift + D` — штатную кнопку приглушения звука, если соответствующие элементы сейчас видимы.

## Проверка

```bash
node --check src/PowerDiscord.plugin.js
node scripts/validate-powerdiscord.mjs
node scripts/smoke-powerdiscord.mjs
```

Валидатор проверяет точное число функций, уникальность ID/ключей/названий, двуязычные подписи, диапазоны, темы, реализацию всех действий, одноразовый чек чата, закреплённые инструменты, очистку ресурсов и отсутствие опасных API. Отдельный smoke-тест проверяет lifecycle, пакетирование DOM, debounce хранилища, ленивые карточки, быстрые режимы, голосовую клавишу и подготовку аватара к сохранению.
