# EmeraldCommandCenter

Русский плагин для BetterDiscord с центром управления интерфейсом и специальной сборкой ровно на **1 000 000 000 строк**.

## Скачать

- [EmeraldCommandCenter.compact.plugin.js — рабочая версия](https://github.com/roman161rusrosrov-cmyk/-plagin/releases/download/v1000.0.0/EmeraldCommandCenter.compact.plugin.js)
- [EmeraldCommandCenter.plugin.js — точная версия на миллиард строк](https://github.com/roman161rusrosrov-cmyk/-plagin/releases/download/v1000.0.0/EmeraldCommandCenter.plugin.js)

Файлы размещены в разделе Releases. Миллиардная версия имеет размер около 1 ГБ и превышает лимит обычных файлов GitHub. Рядом с обеими сборками публикуются файлы `SHA256` для проверки целостности.

> [!WARNING]
> Физический файл на 1 000 000 000 строк невозможно загрузить в BetterDiscord: минимальный размер такого файла превышает максимальную длину JavaScript-строки движка V8. Миллиардная сборка опубликована как точная коллекционная версия. Для реального использования скачивайте `EmeraldCommandCenter.compact.plugin.js`.

## Возможности

- полностью русский интерфейс настроек;
- режим фокуса;
- приватный режим с размытием имён и аватаров;
- компактное отображение сообщений;
- уменьшение анимаций;
- приглушение изображений и видео;
- скрытие GIF, стикеров, подарков, активностей и декораций;
- часы и таймер текущей сессии;
- подсветка сообщений по ключевым словам;
- настройка цветов, размера текста, отступов и скруглений;
- ночной фильтр;
- горячие клавиши;
- локальный импорт и экспорт настроек.

Плагин не получает токены, не отправляет сообщения, не обращается к сторонним серверам и не собирает пользовательские данные.

## Установка

1. Скачайте рабочий файл `EmeraldCommandCenter.compact.plugin.js` из релиза.
2. Откройте Discord.
3. Перейдите в `Настройки → BetterDiscord → Plugins`.
4. Нажмите `Open Plugins Folder`.
5. Переместите файл в открывшуюся папку и включите плагин.

Миллиардная версия содержит то же рабочее ядро в начале файла, а дополнительные строки заключены в единый безопасный JavaScript-комментарий. Однако ограничение V8 срабатывает раньше выполнения кода, поэтому она предназначена для хранения и проверки точного количества строк, а не для включения в Discord.

## Структура репозитория

- `src/EmeraldCommandCenter.core.js` — рабочее ядро плагина;
- `scripts/build-billion-plugin.mjs` — потоковый генератор точного количества строк;
- `.github/workflows/build-release.yml` — автоматическая проверка и публикация релиза.

## Локальная сборка

```bash
node scripts/build-billion-plugin.mjs
wc -l dist/EmeraldCommandCenter.plugin.js
node --check dist/EmeraldCommandCenter.plugin.js
```

Результат должен содержать ровно `1000000000` строк.
