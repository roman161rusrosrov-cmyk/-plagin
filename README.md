# PowerDiscord

Мощный русскоязычный all-in-one плагин для BetterDiscord. В одном устанавливаемом файле находятся **530 реальных локальных функций**: спокойная зелёная тема, настройка интерфейса, инструменты сообщений и медиа, текстовая лаборатория, профили, горячие клавиши, продуктивность, приватность, адаптивность и диагностика.

Основные возможности:

- полностью русский центр управления с поиском, категориями, избранным и ленивой отрисовкой;
- 20 спокойных цветовых тем, включая мягкую зелёную палитру;
- 20 пресетов: фокус, стример, ночь, чтение, минимализм, производительность и другие;
- 250 локальных вариантов отображения элементов Discord: скрытие, компактность, приватное размытие, акцент и приглушение;
- 60 текстовых операций: Markdown, JSON, Base64, URL, регистры, списки, статистика и транслитерация;
- 30 действий с видимым сообщением и 30 действий с изображением или видео;
- заметки, закладки-позиции, избранное, напоминания, Pomodoro, секундомер, быстрые таймеры и часовые пояса;
- три профиля настроек, импорт и экспорт JSON, Safe Mode и диагностика;
- Responsive Engine для компактного, обычного, большого, сверхширокого и вертикального окна;
- централизованная очистка событий, таймеров, observer-ов, стилей и временных DOM-элементов при выключении.

## Безопасность и границы

PowerDiscord работает локально: не читает Discord-токен, cookies или session keys, не отправляет данные в сеть, не пишет сообщения от имени пользователя, не обходит Nitro и не использует `eval`/`new Function`.

Журнал удалённых или изменённых сообщений не реализован. Плагин не сохраняет содержимое чужих сообщений: локальные закладки содержат только идентификаторы и ссылку перехода, а история копирования — только время и число символов.

## Установка

1. Установите [BetterDiscord](https://betterdiscord.app/), если он ещё не установлен.
2. Скачайте `PowerDiscord.plugin.js` по ссылке выше.
3. Откройте Discord → `Настройки пользователя` → `BetterDiscord` → `Plugins`.
4. Нажмите `Open Plugins Folder`, переместите туда файл и включите PowerDiscord.
5. Откройте центр кнопкой `PD` или сочетанием `Ctrl + Shift + P` (`Ctrl + Shift + K` открывает поиск, `Alt + Shift + P` включает паник-приватность).

## Разработка и проверка

```bash
node --check src/PowerDiscord.plugin.js
node scripts/validate-powerdiscord.mjs
```

Валидатор проверяет уникальность и полноту реестра, наличие обработчиков, структуру диапазонов, исполнение всех 60 текстовых преобразований и отсутствие опасных сетевых/токенных примитивов. GitHub Actions повторяет проверку, создаёт SHA-256 и публикует устанавливаемый файл в Releases.
